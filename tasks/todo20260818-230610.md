## Review

The final design uses one store transaction gate from replay lookup through custody and receipt
commit. `TransferableKeyMaterial.Consume` still invokes external code outside its own gate, so the
store gate does not recreate the original ABBA deadlock. The regression's test-only replay-miss
probe makes removal of the store gate fail deterministically, and all thread waits share one
deadline and use background workers.

NFR-3 now draws an implementable execution boundary: exceptions escaping caller delegate
execution—including dependencies called by that delegate—propagate unchanged, while NetCrypto
and dependency exceptions outside that boundary remain subject to normalization. Tests pin a
parser-created `FormatException`, exact nonthrowing rows, exact NetCrypto refusals, and wipe/spend
postconditions.

The touched store fixture also validates and clones its wrapping key after the adversarial pass
proved caller mutation could corrupt `Unwrap`. Public-surface reflection now preserves overload
multiplicity and pins the exact non-static `Consume<T>` and `KeyMaterialReader<T>.Invoke`
signatures. The production change remains documentation-only; behavioral code changes are
confined to the external acceptance-test store and its regressions.
